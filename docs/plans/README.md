# Plans

Implementation plans for multi-step changes, written with the `writing-plans` skill and
carried out with `executing-plans`. File name: `YYYY-MM-DD-<feature>.md`.

Plans are working documents with the lowest precedence in `docs/` (see `docs/README.md`):
they record intent and the decisions made along the way. When a plan conflicts with
`docs/project/`, an ADR or a convention, stop and report the conflict.
